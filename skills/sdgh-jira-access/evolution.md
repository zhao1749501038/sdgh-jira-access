# Evolution — sdgh-jira-access

## v1.2 — 2026-08-20

**改动内容**：
- 将公司 Jira 地址 `https://21tb-jira.21tb.com` 内置为 `setup` 默认值。
- 同事安装时不再填写 Jira 地址，只需连接公司 VPN 并通过系统弹窗输入本人账号和密码。
- 保留可选 `--url` 参数，便于地址迁移或测试环境覆盖。

**改动原因**：
该 Skill 只面向公司内部使用，固定默认地址可以进一步减少安装步骤和填写错误。

**效果评估**：
默认参数测试、本人身份查询、6 个自动化测试和 GitHub 远端安装均已通过；远端安装包的 `setup --help` 已确认显示公司默认地址。

## v1.1 — 2026-08-20

**改动内容**：
- Skill 技术名称从 `jira-api` 改为 `sdgh-jira-access`，界面显示名改为 `SDGH-jira-access`。
- 同步更新源目录、Codex 安装入口、配置目录、钥匙串服务名、关联 Skill 引用和 GitHub 分发地址。

**改动原因**：
用户希望名称直接体现公司 SDGH Jira 的访问用途，便于安装后识别和调用。

**效果评估**：
新名称下的 Skill 结构校验、5 个自动化测试、本人身份查询和 GitHub 远端安装均已通过；旧名称只保留在版本演进和环境变更历史中，不再作为活动入口。

## v1.0 — 2026-08-20

**改动内容**：
- 新建直接调用 Jira REST API 的简单版 Skill。
- 内置查询、详情、字段元数据、创建预检、创建、修改、评论、指派和状态流转命令。
- 写操作必须显式传入 `--confirm`，写后自动回读。
- 使用 macOS 系统弹窗收集本人账号和隐藏密码，密码保存到钥匙串。

**改动原因**：
主要使用场景是 Codex 内安装和分享，直接 API Skill 可以减少 MCP 注册、加载和二次配置步骤。

**效果评估**：
5 个自动化测试、Python 语法检查和 Skill 结构校验均已通过。已用本人身份完成 `whoami`、本人负责工单查询、工单详情、实时创建字段和缺失必填项预检；未执行真实写入。公开仓远端下载安装、结构校验和自动化测试均已通过。
