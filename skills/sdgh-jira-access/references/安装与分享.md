# SDGH-jira-access Skill 安装与分享

只在安装、配置、迁移或分享时读取。

## 本人首次配置

确保已连接可以访问 Jira 的公司网络或 VPN，然后在 Skill 目录运行：

```bash
<Python命令> scripts/jira.py setup --gui
```

由 AI 自动探测可用的 Python 3 命令：Windows 依次尝试 `py -3`、`python`，macOS 依次尝试 `python3`、`python`。用户不需要提供 Python 安装目录或解释器路径。

脚本默认连接 `https://21tb-jira.21tb.com`，无需再让使用者填写 Jira 地址；仍保留 `--url` 参数供地址迁移或测试环境覆盖。

脚本优先通过当前系统的凭据窗口询问本人 Jira 用户名和密码。系统窗口因权限、策略或运行环境无法启动时，自动切换到终端输入；用户名正常显示，密码隐藏。两种方式都不要求用户把密码发到聊天。验证身份成功后：

- Windows 通过 Python 直接调用系统 DPAPI 加密密码，不依赖 PowerShell 完成加密；配置写入 `%APPDATA%\sdgh-jira-access\config.json`，加密内容只能由同一 Windows 用户解密。
- macOS 将密码写入本人钥匙串，配置写入 `~/.config/sdgh-jira-access/config.json`。
- 配置文件不包含明文密码或 Token。

配置完成后可在同一任务中直接运行 `whoami`、`search` 等命令，不需要注册 MCP 或重启 Codex。

## 同事安装

公开仓发布后，让同事在已连接公司 VPN 的 Windows 或 Mac 电脑上向 Codex 发送一句话：

```text
请使用 $skill-installer 安装并继续配置这个 SDGH-jira-access Skill，不要在 Skill 安装完成后停止：https://github.com/zhao1749501038/sdgh-jira-access/tree/main/skills/sdgh-jira-access
```

AI 下载 Skill 后继续读取本文件，自动探测 Python 3 命令并运行一次 `setup --gui`。同事在系统凭据窗口输入本人账号和密码；窗口不可用时在终端继续输入。完成后验证 `whoami` 并说明支持查询、创建、修改、评论、指派和状态流转。

Codex 是否要求批准命令由同事本机的执行权限策略决定，与密码输入方式无关。不要通过关闭安全限制解决批准问题；环境支持记住批准时，只信任这个 Skill 的固定脚本命令，不扩大到全部 PowerShell 或 Python 命令。

## 安全要求

- 不在聊天中收集密码。
- 不分发个人配置文件、Windows 加密凭据或 macOS 钥匙串数据。
- 公开仓按用户授权内置公司 Jira 基础地址，但不写入账号、密码、Token、项目编号或自定义字段映射。
- 公司 Jira 仍只能在公司网络或 VPN 下访问。
