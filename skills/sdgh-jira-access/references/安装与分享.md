# SDGH Jira Access Skill 安装与分享

只在安装、配置、迁移或分享时读取。

## 本人首次配置

确保已连接可以访问 Jira 的公司网络或 VPN，然后在 Skill 目录运行：

```bash
python3 scripts/jira.py setup \
  --url <Jira 地址> \
  --gui
```

脚本通过 macOS 系统弹窗询问本人 Jira 用户名和密码，密码框隐藏。验证身份成功后：

- 密码写入本人 macOS 钥匙串。
- Jira 地址、用户名和钥匙串服务名写入 `~/.config/sdgh-jira-access/config.json`。
- 配置文件不包含密码或 Token。

配置完成后可在同一任务中直接运行 `whoami`、`search` 等命令，不需要注册 MCP 或重启 Codex。

## 同事安装

公开仓发布后，让同事在已连接公司 VPN 的 Mac 上向 Codex 发送一句话：

```text
请使用 $skill-installer 安装并继续配置这个 SDGH Jira Access Skill，不要在 Skill 安装完成后停止；Jira 地址为 <公司 Jira 地址>：https://github.com/zhao1749501038/sdgh-jira-access/tree/main/skills/sdgh-jira-access
```

AI 下载 Skill 后继续读取本文件，运行 `setup --gui`，由同事在系统弹窗输入本人账号和密码。完成后验证 `whoami` 并说明支持查询、创建、修改、评论、指派和状态流转。

## 安全要求

- 不在聊天中收集密码。
- 不分发个人配置文件或钥匙串数据。
- 不在公开仓写入公司域名、项目编号、自定义字段映射或真实凭据。
- 外网无法访问内部 Jira 不代表可以公开内部配置；公开包保持通用化。
